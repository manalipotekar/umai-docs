# UMAI Engine – Minimum Windows Requirements

## Supported OS Versions
- Windows Server 2019
- Windows Server 2022
- Windows Server 2025

## Minimum Hardware Requirements
- **CPU:** 4 vCPU
- **RAM:** 8 GB
- **Disk Space:** 20 GB free
- **Notes:** Tested and verified for stability and acceptable performance.

## Recommended Hardware
- **CPU:** 8 vCPU
- **RAM:** 16 GB
- **Disk Space:** 40 GB free

## Additional Requirements
- **Runtime:** .NET Runtime, WebView2 Runtime
- **Network:** Stable internet connection
- **VM Support:** Works on virtual machines meeting above specs
